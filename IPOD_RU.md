# Автоматические обложки для iTunes и iPod

1. Запусти `start.bat`. При первом запуске программа скачает официальный Python в свою папку `.runtime` и установит зависимости, включая Pillow для обработки картинок. Нужен интернет и 64-битная Windows. Вручную устанавливать Python не требуется; старое окружение `.venv` больше не используется. Последующие запуски используют уже установленные компоненты.
2. Выбери **Spotify**, вставь ссылку на плейлист или отдельный трек и выбери папку с MP3.
3. Нажми **Start Download**. Обложка альбома или сингла из Spotify автоматически встраивается в каждый MP3.

Чтобы добавить обложки к ранее скачанным песням, запусти тот же плейлист с той же папкой. Файлы с прежними именами программа обработает без повторной загрузки аудио. Переименованные или перемещённые файлы автоматически не сопоставляются.

Используется обложка конкретного релиза трека, а не картинка плейлиста или превью YouTube. Картинка преобразуется в обычный RGB JPEG без progressive-кодирования, размером не больше 600 × 600 пикселей. Пропорции сохраняются. В MP3 записывается одна лицевая обложка APIC и теги ID3v2.3 с текстом UTF-16. Это выбранные настройки совместимости, а не заявленный Apple обязательный размер изображения.

Если первая картинка недоступна, программа пробует остальные изображения этого релиза из Spotify, затем существующую встроенную обложку. Если подходящей картинки нет, MP3 сохраняется, а в журнале появляется предупреждение `No usable cover`. Повторный запуск плейлиста повторит попытку. Сообщение `Cover embedded` означает, что обложка записана в файл.

Синхронизацию программа не выполняет. После обработки добавь MP3 в iTunes и синхронизируй iPod самостоятельно. Если iTunes уже импортировал отдельную копию старого MP3, используй обновлённый файл из папки загрузки. Проверка на физическом iPod не выполнялась.

Аудио, как и раньше, подбирается через YouTube; из Spotify берутся сведения о треке и обложка. Для Spotify нужны Client ID и Client Secret в настройках приложения. Genius для обложек не нужен.

Техническая основа: [документация Mutagen по ID3v2.3](https://mutagen.readthedocs.io/en/latest/user/id3.html), [спецификация встроенных изображений ID3](https://mutagen-specs.readthedocs.io/en/latest/id3/id3v2.3.0.html), [обложки в iTunes](https://support.apple.com/en-gu/guide/itunes/itns3027/windows).

Проверка кода: `.\.runtime\python\python.exe -m unittest discover -s tests -v`. Тесты создают короткий синтетический MP3 через FFmpeg, проверяют формат картинки, теги, повторную обработку и неизменность декодированного аудио. Доступ к Spotify и YouTube для тестов не нужен.
